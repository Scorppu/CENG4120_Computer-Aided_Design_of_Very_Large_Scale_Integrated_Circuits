# CENG4120_Computer-Aided_Design_of_Very_Large_Scale_Integrated_Circuits
HW2-B (Programming Assigment)

To run this program:
1. Compile by typing in the console: "g++ hw2.exe hw2.cpp"
2. After compiling type: "./hw2 <input_file.txt> <output_file.txt>"
The output will be written in the <output_file.txt>

The visualization program can also be accessed within the same directory:
1. In the console type: "python visualize.py <output_file.txt> <result.png>"
The result will be printed in <result.png>
